# 🔐 Password Generator App

A simple and modern password generator built with **HTML, CSS, and JavaScript**.  
Generate strong, secure passwords instantly with customizable options and one-click copy support.

---

## 🚀 Live Demo

https://sanjanapasswordgenerator.netlify.app/

---

## ✨ Features

- 🔢 Custom password length input
- 🔠 Toggle uppercase letters
- 🔢 Toggle numbers inclusion
- 🔣 Toggle symbols inclusion
- 🔐 Generates 2 secure passwords at once
- 📋 Click to copy password
- 🔔 Toast notification on copy
- 🎨 Dark modern UI design
- ⚡ Instant password generation

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 🎮 How to Use

1. Enter desired password length
2. Choose options:
   - Uppercase letters
   - Numbers
   - Symbols
3. Click **Generate passwords**
4. Two secure passwords will be displayed
5. Click 📋 icon to copy instantly

---

## 🔑 How It Works

- Lowercase letters are always included by default
- Uppercase, numbers, and symbols are optional
- Characters are randomly selected using JavaScript `Math.random()`
- Two passwords are generated at the same time for convenience
